B1 / D435i + MateBook 13s 2023 EMF-16 双夹支架
2026-10-11；单位：mm；可调概念试装版，待实测。

先打开《B1_D435i双夹支架_详细设计与试装说明.pdf》。这是详细原型设计及数字几何核验，不是经过实机适配、承载测试的成品。电脑示意包络、12 mm 底座厚度、110°开屏角均不是用户实测值。STEP 与 STL 不等于已通过安全使用验证。

结构：一体主件 ×1 + 同款活动压脚 ×2。另有一枚独立单夹试片，只用于提前验证夹口和软垫接触，不是正式安装的额外零件。5个直径25 mm粘贴座与相机支架同体，真实三维错层，贴面中心跨度99×87×44 mm。

优先顺序
1. 拍开屏右侧、左侧和底面的照片（带直尺），量候选两点处实际“底座”厚度及硬边宽度。闭盖整机厚度不能代替此值。
2. 先打印 03_optional_fit_coupon_x1.stl 一件和 02_pressure_shoe_x2.stl 一件；安装软垫与五金，在手托住电脑的条件下轻轻试夹。
3. 确认上下垫均完全落在硬边，不压键帽、触控板或缝隙；接口插头能正常插拔；风口、脚垫、转轴和开盖路径不被挡。
4. 修改参数、重新生成和复核；符合条件后才打印整件。未验证的主件不要直接夹电脑并移动。

夹持与五金
- 只有夹厚用 M5 金属螺杆现场机械调节。名义目标8–22 mm，依赖2 mm软垫、指定压脚、30 mm有效螺纹长，尚未测到打印公差与软垫压缩。
- 夹距72 mm、后夹位置Y=88 mm、前夹Y=160 mm、咬入深度和避让尺寸均为参数化重打，不是滑槽调节。
- M5螺母必须从下夹臂的上方落入六角窝；确认自然到位，不要用锤敲。采用 DIN934 M5，AF8 mm、厚4 mm。其他标准/厂家的更厚螺母不能直接替换。
- 两个压脚是可取出的活动件，松夹时用手接住；不是永久卡在螺杆上的球铰。盲孔朝螺杆，软垫朝电脑底壳。
- 相机后固定 M3×10 两颗，每孔硬垫片总厚名义1 mm：10-7-1=2 mm。装相机前，先穿过打印件和垫片，实测突出1.8–2.2 mm且严格小于3 mm。长度不合适就换螺钉/垫片，不许拧到底硬顶。
- 相机官方0.4 N m数值只涉及相机固定，不能用于电脑夹或PLA结构。电脑夹交替手指轻紧，不用工具加力，没有验证允许夹力/扭矩。

使用边界
- 用户始终双手托住电脑，支架仅用于相机与动捕点。严禁提着支架搬电脑、悬吊电脑或把夹架当手柄。
- 装上夹具后不要合盖；不要直接把电脑平放在桌面压支架、旋钮或螺杆。先拆下支架再平放；如采用其他支承，须独立确认支承落点、稳固与散热。
- 不堵USB、耳机口、风口、脚垫和转轴。电缆留自然松弛，固定在支架扎带孔，避免插头承受拉扯；示意16×20×35 mm USB插头包络未代表实物。
- 相机光轴朝-Y，即屏幕后方环境。必须用实际开屏角逐一看深度/红外/RGB画面，确认屏幕与上盖未挡视野，不能只查外壳碰撞。
- 安全绳只在已有可靠电脑挂点且不跨键盘/风口时选配；无可靠挂点就不乱绑，尤其不能绑屏幕。安全绳不能代替手托电脑。
- PLA怕热和长期受力蠕变。出现滑动、开裂、明显挠曲、壳体压痕、键帽受压、异常发热或USB松脱，立即停止，拆下改设计。无额定承载或疲劳认证。

打印
主体外形153.5×173×134 mm。STL已按建议姿态落到Z=0，下夹臂朝床。173 mm深度加两侧3 mm brim共179 mm；仍须检查真实打印有效区。不能整体缩放模型来适应打印机。空间斜撑和上夹臂需要支撑；把螺母窝/螺杆孔设为支撑屏蔽，并在切片预览确认支撑可从侧面拆出。压脚盲孔朝下，小孔顶可先试桥接。完整参数在PDF，均为切片起点，不是强度证明。

文件
STL_PROTOTYPE/：主件 ×1、同款压脚文件打印 ×2、可选试片 ×1。只打印这些文件，不打印参考相机/金属件/球体。
STEP/：可编辑中性实体主件、压脚、试片、参考装配和3个实体截面。参考装配用于查看，不直接作为整件打印。
params.json + build_B.py：参数化CAD源（CadQuery 2.7.0、NumPy）。同目录执行 python build_B.py 重新生成 STEP、STL、QA.json、render_meshes.json；再执行 python verify_stl.py 独立读回检查实际STL。
render_B.py：Blender 4.3.2实际CAD网格渲染源；make_figures.py：Pillow/Matplotlib注释图；make_manual.py：ReportLab详细手册。
推荐生成顺序：build_B.py → verify_stl.py → blender -b -P render_B.py → make_figures.py → make_manual.py。渲染和手册中的文字尺寸是本版固定说明；修改CAD后必须同步改图文，不能将旧尺寸页当自动工程图。
BOM_采购.txt：规格、数量与到货核验；QA.json、STL_validation.json、STEP_validation.json：当前数字检查记录；SHA256SUMS.txt：本包文件校验。
Windows用户仅查看和切片不必运行源码。重新制图需安装对应Python依赖与Blender；make_figures.py中的中文字体路径为本次制图环境路径，换成自己电脑已有的中文字体文件即可。CAD生成源不依赖该字体。

参数修改规则
clamp_rear_y、clamp_pitch决定两夹位置；jaw_intrusion和contact_center_x等共同决定接触范围。不要单独改一项就默认无干涉。相机45 mm孔距与3 mm最大旋入是固定设备约束，不能为缩放而改变。marker座坐标是设计参考，不是实测球心；用实际marker球心重新建立动捕刚体并做相机外参标定。任何改动均需重新检查CAD有效性、实体分离/干涉、STL和打印床范围，重新实机试装。

已核验与尚未核验
当前3款打印几何均为一个有效实体；3份实际STL读回均无零面积三角面、无开边/非流形边、无不一致边方向且有正体积。当前参考装配所列几何干涉体积为0。以上不是完整网格自交证明、打印质量保证或机械强度/防滑实测。实机接口与接触面缺失仍是精配阻断项。72 mm夹距的力矩分担算例只用于解释受力，不表示电脑可承受对应夹力。

待量清单（以实际安装姿态为准）
1. 候选两个夹点处，底座厚度、顶面硬边可用宽度、底面平坦可用宽度。
2. 从后缘到USB/耳机/风口/脚垫/转轴的范围，含真实插头及插拔余量；左右侧照片。
3. 常用开屏角、屏幕外轮廓、相机前向画面无遮挡测试。
4. USB插头宽厚长及电缆自然弯线尺寸；marker底座直径/高度和球径。
5. Creality具体型号、喷嘴、真实可用打印范围。
